# Shockit Games — GitHub Pages files

This package is for the public repository `shockitgames/shockitgames.github.io`. It contains a static studio homepage, a Bloom & Bow privacy-policy page and a support page. It uses no JavaScript, external fonts, analytics scripts, or paid services.

## Upload in GitHub
1. Extract `ShockitGames_GitHubPages.zip` on your computer.
2. In the repository, open **Code → Add file → Upload files**.
3. Upload `index.html`, `bloom-and-bow-privacy.html`, `support.html`, `styles.css`, and `bloom-and-bow.svg` directly into the repository root. You may also upload this README to replace the initial README. Do not upload the ZIP itself or put all files inside an extra folder.
4. Commit the files to **main**.
5. Under **Settings → Pages**, use **Deploy from a branch → main → / (root)** and save if not already configured.
6. Wait for the Pages deployment to finish. GitHub says publication can take up to 10 minutes. Open the URLs below in a signed-out/private browser window and check that they load without requesting access.
